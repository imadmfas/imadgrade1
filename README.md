# مكتبتي الملوّنة — الصف الأول الابتدائي

مكتبة تفاعلية مجانية لكتب الصف الأول الابتدائي في المنهج العراقي (طبعة 2026). يتحول فيها كل درس إلى صفحات ملوّنة فيها ألعاب وأصوات ورسوم، يستعملها الأطفال والأهل والمعلمون دون تسجيل ودون إعلانات.

**الرابط:** https://imadmfas.github.io/imadgrade1/

إعداد البروفيسور عماد محمد فرحان، باستعمال المساعد الذكي كلاود (Claude).

## طريقة الاستعمال

1. افتحوا الرابط على الهاتف أو الجهاز اللوحي أو الحاسوب.
2. يلمس الطفل غلاف الكتاب، ثم «هَيَّا نَلْعَبُ»، ثم درساً من طريق المغامرة.
3. الراوي يقول التعليمة بصوت مسموع، وزر السمّاعة يعيدها. كل لعبة تمنح نجمة، ونجوم الدرس كلها تمنح ملصقاً.
4. لا مؤقت ولا خسارة. بعد محاولتين يلمع الجواب الصحيح ويُنطق.
5. **ركن الوالدين والمعلم:** اضغطوا مطوّلاً ثلاث ثوانٍ على زر الترس ⚙️ ثم أجيبوا عن سؤال الجمع. فيه إرسال ملاحظة عبر واتساب، وتقدّم الطفل، وإعدادات الصوت والحركة، والشهادة.
6. لمشاركة درس محدد انسخوا رابطه وهو مفتوح؛ يفتح الدرس مباشرة.

يُحفظ التقدم على الجهاز نفسه فقط، ولا تُجمع أي بيانات عن الطفل.

## للمطوّرين

المصدر في `engine/`: محرك مشترك (`src/`)، وبيانات الكتب (`books/`)، وأدوات Python (`tools/`)، والاختبارات (`tests/`).

```bash
cd engine && npm ci
python3 tools/add_lessons_reading.py      # يولّد lessons.js و audio-list.csv
python3 tools/lint_ar.py                  # فحص الصيغ العربية الممنوعة
WA=9647812346562 node build.mjs           # يبني index.html للرف ولكل كتاب جاهز
node tests/screenshot-all.cjs             # لقطات على أربعة مقاسات، يطبع no errors
node tests/play-all.cjs                   # يحلّ كل الألعاب آلياً ويتحقق من النجوم والحفظ
```

التسجيلات الصوتية: ضعوا ملفات mp3 (أحادية، 48–64 كيلوبت/ث) في `reading/audio/` بالأسماء الواردة في `reading/audio/audio-list.csv`، ثم أعيدوا البناء.
